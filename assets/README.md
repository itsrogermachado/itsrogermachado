## Antes de subir qualquer print

**Nenhum dado real de cliente pode aparecer.** Nome, telefone, e-mail, CPF, valor
de cobrança e print de conversa de WhatsApp saem da imagem — troque por dado
fictício antes da captura, ou borre depois. Uma vez no repositório público, a
imagem fica no histórico do Git mesmo que seja apagada depois.

## Como capturar

- Largura de 1440 px ou mais; a imagem é exibida a 49% da coluna
- PNG, abaixo de 1 MB por arquivo
- Tela cheia da aplicação, sem a barra de favoritos do navegador
- Se o app tiver tema escuro, prefira o claro: contrasta melhor no README
